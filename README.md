# رصد — RASAD

آزمایشگاه اطلاعات متن‌باز به فارسی. هر پرونده‌ای — با هر قالب و هر حجم — در مرورگر هش و کالبدشکافی می‌شود، نشانه‌ها استخراج می‌گردد، سپس اوسینت گیت‌هاب ردپا را به پروفایل و مخزن وصل می‌کند و لینک گزارش می‌سازد.

**مخزن:** [github.com/Reymond-Reddington/rasad-osint](https://github.com/Reymond-Reddington/rasad-osint)

## چرخه کار

1. رها کردن فایل یا چسباندن متن / شناسه
2. هش قطعه‌ای MD5 · SHA-1 · SHA-256 در مرورگر (بدون سقف حجم اعلامی)
3. استخراج IOC: ایمیل، دامنه، آی‌پی، گیت‌هاب، توکن، کیف پول
4. تحلیل هوشمند (اختیاری) با grok-4.5 روی نمونهٔ محدود
5. اوسینت GitHub REST: کاربر، مخزن، لینک زنده
6. ایجاد گزارش و گرفتن لینک `/r/{id}` + مارک‌داون آمادهٔ گیست

## خط‌ها

| خط | مدل | نقش |
| --- | --- | --- |
| هوش پرونده | rasad-hash / rasad-ioc | کالبدشکافی محلی، فایل کامل به سرور نمی‌رود |
| اوسینت گیت‌هاب | github-recon + grok-4.5 | پروفایل، مخزن، پرس‌وجو، لینک گزارش |

## حریم

پروندهٔ کامل هرگز به سرور فرستاده نمی‌شود. گزارش‌ها در `localStorage` همین مرورگر می‌مانند. برای انتشار عمومی، مارک‌داون را در گیست یا مخزن خودتان بگذارید.

این ابزار برای تحقیق مشروع است.
